# CourtSense website

The landing page for [CourtSense](https://github.com/EmirCobanOfficial/courtsense): a tennis coach's training video, turned into movement data with Meta SAM 3.1 and Muse Spark 1.3.

Live: https://emircobanofficial.github.io/courtsense-site/

Built during the Meta Global AI Developer Hackathon (Oct 26 – Nov 4, 2026). The footage is from our coach's training session, used with both players' consent.
